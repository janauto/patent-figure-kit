?我没有 STEP 怎么办

墨线只收 STEP 装配体（.stp / .step）。主流 CAD 一句话导出：

  • SolidWorks文件 → 另存为 → 类型选 STEP AP214（.step）
  • Creo文件 → 另存副本 → 类型 STEP → 实体 + 面
  • UG / NX文件 → 导出 → STEP214
  • Inventor导出 → CAD 格式 → STEP（AP214）
  • Fusion 360文件 → 导出 → STEP（.step）

只有 2D 图纸或照片？本版不收——它把 3D 装配体变成规范附图，不做描边。

设AI 通道

AI 只做两件事：给零件起中文名、把方法描述整理成流程图语义。 编号与版面一律由程序完成。

接接入 MCP / API

MCP 客户端

在 MCP 客户端（如 Claude Code、Codex） 里新增一个自定义连接器，地址填下面这行。

可用工具：列出工程、读零件清单、写零件中文名、出图（交底版 / 递交版 + 附图说明）、 按 JSON 或一段文字画流程图。客户端当「起名的人」，编号仍由程序发。

⚠ 这个地址只在本机可达。要从云端连入需另行部署或内网穿透，属对外暴露服务，请先评估。
