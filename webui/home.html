工程

设置 · 大模型通道

大模型只做两件事：给零件起中文名、把方法描述整理成流程图语义。编号与版面一律由程序完成。

密钥保存在本机 ~/.config/patent-workbench/config.json（仅本人可读），不会写进任何工程文件或日志，页面上只显示末 4 位。

外部调用 · 千问办公 / API

千问办公（MCP）

在千问办公「连接器 / MCP」里新增一个自定义连接器，地址填下面这行；或把 JSON 片段并进 ~/.qwenworkcn/mcp.json 的 mcpServers。

可用工具：列出工程、读零件清单、写零件中文名、出图、取附图（含件号表与附图说明）、 AI 起草、按 JSON 画流程图、文字生成流程图。千问自己就能当「起名的人」，编号仍由程序发。

⚠ 这个地址只在本机可达。若千问办公的 MCP 是从云端连过来的，需要另行部署或内网穿透——那属于对外暴露服务，请先评估。
